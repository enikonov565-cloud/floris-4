## Принципы, зафиксированные владелицей

1. **Уровень — Awwwards**: нестандартная сетка, дорогой минимализм, "шикарная адаптация под все устройства".
2. **Технологии**: чистый HTML/CSS/vanilla JS, без сборщиков — сознательное решение, не менять.
3. **Переходы между страницами**: View Transitions API (нативный cross-document, `@view-transition{navigation:auto}` в CSS) — НЕ document.startViewTransition() (это SPA-паттерн, не подходит для MPA). Хедер должен визуально не мигать между страницами (`view-transition-name:site-header`).
4. **Анимация — точечная, не равномерная**:
   - Витринные/навигационные блоки (каталог, категории, hero) — можно смело: shared-element переходы, reveal-on-scroll, магнитные hover-эффекты.
   - Блоки цикла сделки (карточка товара, заказ, корзина, FAQ, контакты) — анимация тихая/минимальная, приоритет — маркетинговая логика и ясность CTA, ничего не должно отвлекать от решения купить.
5. **Типографика**: убрать "гигантизм" (особенно был в футере), контрастная шкала размеров (коэффициент ≥1.25 между уровнями), осознанный letter-spacing (капс/мелкий текст — шире трекинг), группировка списков по правилу внутреннего/внешнего отступа (элементы одной смысловой группы теснее друг к другу, чем к соседней группе) — касается футера, FAQ, УТП-списков.
6. **Карточка товара**: 50/50 split, крупное фото без рамки на всю высоту, тонкая типографика, + блок "с этим товаром покупают" (upsell, тихая анимация).

## Важный технический урок этой сессии

Агенты типа `general-purpose`, запущенные в фоне на длинные задачи (правки styles.css, полная пересборка index.html), несколько раз падали с ошибкой `API Error: Connection closed mid-response` на середине работы — это сетевая нестабильность, не ошибка в задаче. Каждый раз перед перезапуском **проверяй целостность файла** (баланс `{`/`}` в CSS, баланс тегов в HTML через python3 подсчёт) — как правило, файл остаётся в валидном состоянии даже при обрыве, потому что агент сохраняет через Edit-инструмент постранично, не держит гигантский diff в памяти. Перезапускай агента с "продолжи, не начинай с нуля — вот что уже сделано" вместо полного повтора задачи.
